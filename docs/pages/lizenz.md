# Lizenz

## Daten und API: CC BY 4.0

Die Preisdaten (Verzeichnis `data/` im Repository) und dieselben Daten über die API unter
`https://tldcost.io/api/v1/` stehen unter der Lizenz
[Creative Commons Namensnennung 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.de).
Sie dürfen die Daten für jeden Zweck nutzen, weitergeben und verändern, auch kommerziell. Bedingung:
Sie nennen die Quelle, verlinken die Lizenz und geben an, ob Sie etwas geändert haben.

Namensnennung zum Beispiel so:

> Quelle: tldcost.io (CHnet Solutions Plus UG), CC BY 4.0

mit Link auf <https://tldcost.io/> und <https://creativecommons.org/licenses/by/4.0/>.

Jeder Datensatz nennt seine Quelle (`evidence.source_url`) und den Abrufzeitpunkt
(`evidence.fetched_at`). Anbieternamen und Marken gehören ihren Inhabern.

Lizenztext im Repository: [`data/LICENSE`](tldcost:repo/blob/main/data/LICENSE),
verbindlicher Rechtstext: <https://creativecommons.org/licenses/by/4.0/legalcode.de>.
